# Projetos de Hardware

Projetos de arquitetura de computadores desenvolvidos durante meus estudos em Engenharia de Computação, abrangendo desde simulação de processadores até descrição de hardware.

Inclui um simulador do algoritmo de Tomasulo (C++) explorando execução fora de ordem e escalonamento de pipeline, e um processador nRisc monociclo implementado em Verilog HDL.
